# **Cinch – Inclusive Communication for the Deaf & Mute Community**

Cinch is a **Flutter-based Android application** built to empower **deaf and mute users** by enabling seamless, inclusive communication. The app connects specially-abled individuals within the same location and provides **real-time sign-language recognition (English alphabet)** using on-device image processing.

Hosted on **Firebase Authentication** and **Firestore**, Cinch ensures secure, scalable, and reliable user management and data handling.

---

## 🚀 **Features**

### 👥 **Community Connections**

* Discover and connect with nearby deaf and mute users.
* Location-based user discovery using Flutter plugins.

### 🤟 **Real-Time Sign Language Recognition**

* Recognizes **English alphabet gestures** via device camera.
* On-device ML ensuring fast performance and data privacy.

### 🔐 **Secure Backend**

* Firebase Authentication for user sign-up/sign-in.
* Cloud Firestore for storing user data, connection details, and chat metadata.

### 💬 **Inclusive Communication**

* Chat and interact using recognized sign-language gestures.
* Accessible UI designed with inclusivity in mind.

## 📱 **Installation**

```bash
git clone https://github.com/your-username/cinch.git
cd cinch
flutter pub get
flutter run
```

Requirements:

* Flutter SDK installed
* A valid `google-services.json` inside `android/app/`
* Firebase project configured
